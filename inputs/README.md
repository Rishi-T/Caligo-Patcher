# Put your APK here

The original `CaligoChaser 1.0.4.apk`. That is all this tool needs - the
resources, native library and dex all come from that file and are carried
through unchanged; nothing is downloaded and no game data is included here.

Exactly one `.apk` in this folder (subfolders are fine) unless you set
`input.apk` in `config.yaml`.
